# Kasa

Kasa hesabı, hareket ve kullanıcı profilini yöneten web uygulaması.

## Ne var

Hesap, hareket ve profil controller'ları ile giriş ekranı vardır. Veri erişimi ayrı bir repository projesindedir.

## Çalıştırma

Çözümdeki web veya API projesinde şu komutu çalıştırın:

```powershell
dotnet run
```

Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET 7, ASP.NET Core MVC, Entity Framework Core ve SQL Server.
